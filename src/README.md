# مصدر «ميقات»

`index.html` في الجذر **ملف مُولَّد** من هذه الأجزاء (يبقى مُلتزَماً به لأن النظام يُسلَّم ملفاً واحداً ولأن الاختبارات وآلية التحديث OTA تقرؤه نصياً).

- عدّل الأجزاء داخل `src/html` و`src/styles` و`src/js` فقط.
- `npm run dev` يشغّل خادماً محلياً ويعيد التجميع تلقائياً عند أي تعديل.
- `npm run assemble` يكتب `index.html`، و`npm run assemble:check` يتحقق من تطابقه (يعمل في CI).
- ترتيب الأجزاء في `src/parts.json`. الأجزاء تُضمّ نصياً بالترتيب (مجال وحدة JS واحد مشترك)، فأضف الملف الجديد في مكانه من القائمة.
